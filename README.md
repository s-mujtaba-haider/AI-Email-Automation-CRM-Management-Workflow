# AI Email Automation & CRM Management Workflow
This workflow automatically handles incoming emails using an AI agent. When a new email is received, it extracts details like sender, subject, and message content, then analyzes the intent (such as inquiry, support, or scheduling). Based on this, it generates a structured, professional HTML email reply with proper formatting and a clean conversation thread.

In addition to replying, the workflow integrates with a CRM system to manage contacts. It checks if the sender already exists, creates or enriches their profile if needed, and can retrieve business-related information or services to include in the response. It also handles special cases like appointment scheduling by fetching available time slots and confirming bookings when required.

Finally, the workflow ensures full automation by first creating the email and then immediately sending it once generated. It logs interactions, updates contact status (e.g., marking invalid emails), and categorizes leads (like interested or ready for a call). Overall, it acts as an end-to-end intelligent system for automated communication, lead handling, and customer engagement.
